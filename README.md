# QA Prep

A free, curated self-study path for QA / SDET interview prep — programming basics, testing fundamentals, UI and API automation, SQL, and CI/CD — plus a capstone project to tie it together.

**Live page:** set after first deploy (see below).

## Why this exists

Resource lists get copy-pasted into notes apps and never looked at again. This repo turns the list into a single checklist page you can actually track progress on (checkboxes persist in your browser via `localStorage`), so you stop re-searching for the same links.

## Structure

- `index.html` — the whole site. No build step, no dependencies. Deployed as-is via GitHub Pages.

## Updating

Edit `index.html` directly and push to `main` — GitHub Pages redeploys automatically within a minute or two.
